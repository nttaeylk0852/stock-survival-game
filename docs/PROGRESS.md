## 확정 규칙 (재해석 금지)

### 스탑로스
지정가와 짝. “이 가격 이하면 시장가 매도”. **sell only**.
`price` = 조건가. 발동 = 기존 AMM 시장가 매도(수수료·슬리피지 그대로).
휴장 = **신규 접수만** 금지. 이미 걸린 손절은 유지. **취소는 휴장에도 허용.**
발동 실패(주식 0 등)여도 주문을 `cancelled`로 만들지 말 것.

### 직장 (묶음 10)
대가·거래제한 없음.
- 정규 급여 = `(mealCostBase + restCostBase) × 지금CPI` + `starterCash × 0.10`(**CPI 안 곱함**).
- 알바 급여 = `restCostBase × 지금CPI` + `partTimeExtra`(고정).
- 지급 = 게임일 개장(09:00). `gameTime.totalMinutes`만 사용. `Date.now()` 금지.
- 정규 종료(먼저 오는 쪽): 게임 7일 **또는** 순자산 ≥ `starterCash × N`(예: 2).
- 정규 끝나면 그 시즌 정규 재취업 불가. 알바는 시즌 내내 가능.
- 세계관: 정규 = 적응 지원이지 평생 직장 아님. 알바 = 구멍이지 보험 아님.

### 랭킹 (묶음 11)
살아있는 캐릭터의 **지금** 순자산 + 내 등수. 테이블·훈장보드·뉴비보드 없음.

### 웹 (묶음 12)
Expo 신규 금지. `packages/web/public` 정적 파일 + Express 서빙.
화면 4장: 시세+원인 / 뉴스 / 생존 / 주문.
온보딩 한 줄: 금리↑ → 밥값↑ → 손절 걸어라.
요인 이름+방향(▲/▼/—)만. 수치·수식·조작캡 비공개.
뉴스 **언제**(chain 딜레이)는 읽히게, **얼마**만 아이콘으로.

### 기관 (묶음 13)
의결 총합 30%는 기존 `userInfluenceCap`. 월(게임 30일). 미달 박탈. 차순위 거부 가능.
**flag false로만 커밋.** 웹에 사람 여러 명 들어온 뒤에 켠다.
