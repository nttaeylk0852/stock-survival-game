## 규칙

- 한 번에 **묶음 1개씩** 구현.
- 묶음 완료마다 `npm test` + `npm run dev:server` 로 스모크 확인.
- 밸런스 수치는 `config/*.json` 으로만 튜닝 (코드 수정 최소화).
